Grabbit: the window IDM users know, made calm

The chosen direction for Grabbit, drawn across every window a user meets, with the app's own words. Every command, setting and shortcut keeps its place; what changes is colour, type, spacing, controls and one consistent icon family.

Why Graphite

Grabbit's promise is IDM's window, faster and free. Graphite keeps that window so a switcher is at home in seconds, and makes it modern through colour, type, spacing, flat controls and one icon family. Grabbit's theme engine already carries colours, corners, control styles and icon sets, so most of it ships as a theme.

Rules every window follows

  • The default button comes last, filled with the accent, in every window. (Today some Grabbit windows put it first; Graphite moves it.)
  • Labels sit beside fields in one 112 px column, or a 240 px column where the app's label is a sentence; one corner scale (6, 8, 10 px).
  • Greyed means not possible now, drawn one way everywhere.
  • Status is a word and an icon, never colour alone.
  • Windows of their own (main, progress, torrent) show the app's icon; dialogs don't.

New, and optional

  • Paste bar under the toolbar: an address or magnet link, Enter adds it (View menu hides it).
  • Details pane beside the list: the selected download without its window (View menu, or the toolbar's Details button).
  • Options pages listed down the side instead of two rows of tabs that reorder when clicked.

Colour directions

Three roles in every palette: the base (window and text), the primary (what you selected, checked or focused) and one outlaw colour kept for what is moving: the default button, progress and the app's mark. Errors always keep a hue of their own. Each palette's greys carry a trace of its own hue, and the hot colour gets a two-tone finish, with a soft glow in dark. Main window

Menus share the title bar. The toolbar keeps IDM's eleven buttons in their order, in five groups. The categories keep their tree, flatter. Status shows progress inside the row.

Toolbar

Add URL, Add Torrent, Resume, Stop, Stop All, Delete, Delete Completed, Options, Scheduler, Start Queue, Stop Queue: IDM's order. Add Torrent and both queue buttons keep their drop arrows. With the stopped download selected, Resume and Delete are live and Stop greys; selecting a running download greys Resume and Delete, as today.

Find

The title bar's Find button opens the Find file dialog, the same as Ctrl+F; F3 finds the next match.

List

The app's columns and order: Source (Web or Torrent), File Name, Q, Size, Status, Time left, Transfer rate, Last Try Date, Added; Upload speed, Peers, Share ratio and Description from the column chooser. Widths, sort and filters stay as saved.

Details pane

Progress by connection, speed, time left, resume capability, folder, address and queue for the selected download, with Stop, Open folder and its progress window.

Adding a download

From the paste bar, Add URL or the browser, the address lands in Download File Info. A magnet link or a torrent address goes to Add torrent; a page from a supported video site goes to Download video. Download Later asks which queue. When a debrid account takes the address, Download File Info adds a check box, Download through and the service's name.

Downloading

The progress window keeps its three tabs, its fields and its connection list; each connection is a segment, so a slow part shows at a glance. Speed Limiter settings is the window behind Downloads, Speed Limiter.

Finished

Download complete says where the file is and what to do with it; on Windows its handle drags the file into a folder or an app. File Properties holds everything about one download.

Torrents

A torrent file or a magnet link opens its file tree. Once added, its window has five tabs instead of the web download's three; General shows sharing after it finishes. Torrent settings covers sharing limits and the network. While a magnet link is looked up, Add torrent says how the search goes.

Video from a page

On first start Grabbit offers the two free helpers that find videos (yt-dlp) and join picture and sound (ffmpeg). Then a page's address lists its qualities, with subtitles if it has them; a playlist lists its videos. Galleries go through gallery-dl, and Helpers says which copy of each program Grabbit uses.

Batch, link grabber and RSS

Three more ways in: a numbered series of files, every link on a page, and feeds that download new episodes by rule.

Queues and the scheduler

Queues on the left; the chosen queue's schedule or its files on the right. A queue's kind is fixed when it is made, so the other kind shows greyed. Under the wake option, the line says when the computer will wake, or what the system needs first (Windows, Linux and macOS differ). When a queue finishes and the computer is set to turn off, Grabbit counts down first.

Options

The same twelve pages, in the app's order, down the side; every page is drawn. Below them, the windows the pages' buttons open. Two controls open nothing in Grabbit today and stay greyed here as they are in the app: Advanced / Socks... on Proxy / Socks, and Virus checking settings with its Edit... button on Downloads.

Proposals, not in Grabbit yet: the two greyed controls above open nothing in the app today (Advanced / Socks waits for the proxy work). If they get windows, these are the Graphite drafts.

Finding and organising

Find file searches names, descriptions and addresses. Categories pick a folder by file type.

Delete, redownload and errors

Deleting and redownloading ask first, in the app's words. A failed download says why in its window, and Resume tries again.

Around the app

The notification area menu, the drop target, the browser extension offer, updates, About, checksums and the crash report.

Short questions and notices

The small windows Grabbit raises along the way, each with the app's own words and buttons.
